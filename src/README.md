# Dependencies

Dependencies are managed with [poetry](https://python-poetry.org/docs/).

# How to use

- Start in the root folder `biblioteko`
- Write `python -m venv venv` in your terminal at the root folder to make the venv (if it's not already done)
- Go into the virtual environment by typing `venv/Scripts/activate` on Windows
- Write `poetry install` to install every dependencies (⚠️Do it in the venv, not outside)
- Go into the `src/` folder `cd src`
- Use the program by typing this into your terminal `python app.py`
