# Diagrammes

Utilisation de chatgpt pour générer un diagramme de séquence selon le diagramme global de l'application et du scénario `upload_contenu_inapproprie`

# Présentation du scénario

Nous avons présenté le scénario à l'oral.

M. Launay nous a donné des informations pertinentes :
- Faire une docstring y compris au début du fichier pour le module complet
- Faire des docstrings pour les méthodes privées
- Mettre plus de constantes en en-têtes ou dans le .env (comme par exemple les URL pour utiliser les API)
- Utiliser du snake case pour les méthodes
- Ajouter une légende sur nos diagrammes pour nos choix de modélisation
- Cardinalité sur les diagrammes
- Eviter les "s" sauf si on parle au pluriel
